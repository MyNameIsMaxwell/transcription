# Банк идей СТиМ — чат вместо анкеты

Одностраничный чат на [assistant-ui](https://github.com/assistant-ui/assistant-ui) (Next.js):
сотрудник рассказывает идею текстом или голосовым, бот (Yandex Alice AI) задаёт уточняющие
вопросы по шаблону, показывает карточку идеи, сотрудник отправляет её кнопкой.
Идеи сохраняются в SQLite, просмотр — на странице `/admin`.

Это отдельный проект внутри репозитория: свои зависимости, свой `.env.local`.
С Python-приложением транскрибации в корне репозитория не связан.

## Что нужно

| Что | Зачем |
|-----|-------|
| **Node.js 22.5+** (проверено на 22.19) | Next.js и встроенная SQLite (`node:sqlite`). Проверить: `node -v` |
| npm (идёт с Node.js) | установка зависимостей |
| Yandex Cloud: сервисный аккаунт + API-ключ, ID каталога | модель Alice AI и распознавание голоса (SpeechKit) |
| Роли аккаунта: `ai.languageModels.user`, `ai.speechkit-stt.user` | без них Яндекс отвечает 403 |
| HTTPS на сервере | браузер даёт микрофон только по HTTPS (или на `localhost`) |

Python, ffmpeg и отдельная база данных не нужны. Все npm-зависимости перечислены в `package.json`,
точные версии — в `package-lock.json` (аналог `requirements.txt`).

## Установка

```bash
cd idea-chat
npm ci                        # ставит зависимости строго по package-lock.json
cp .env.example .env.local    # затем заполнить .env.local
```

## Настройки (.env.local)

Все переменные с комментариями — в [`.env.example`](.env.example).

| Переменная | Обязательна | Что это |
|------------|:-----------:|---------|
| `YANDEX_API_KEY` | да | API-ключ сервисного аккаунта Yandex Cloud |
| `YANDEX_FOLDER_ID` | да | ID каталога Yandex Cloud |
| `ADMIN_PASSWORD` | да* | пароль на `/admin` (логин любой). *Без него `/admin` закрыт, чат работает |
| `YANDEX_LLM_MODEL` | нет | модель диалога, по умолчанию `aliceai-llm/latest` |
| `YANDEX_LANG` | нет | язык распознавания, по умолчанию `ru-RU` |
| `RATE_LIMIT_WINDOW_MIN` / `_PER_CHAT` / `_PER_IP` | нет | лимит: 20 запросов на диалог и 200 на IP за 10 минут |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`, `IDEAS_EMAIL_TO` | нет | письмо с каждой новой идеей; без них письма не шлются |

`YANDEX_API_KEY` и `YANDEX_FOLDER_ID` — те же значения, что для SpeechKit в корневом `.env`
приложения транскрибации.

## Запуск

Разработка (автоперезагрузка):
```bash
npm run dev          # http://localhost:3000
```

Сервер:
```bash
npm run build
npm start            # порт 3000; другой порт: npm start -- -p 8080
```
- Запускать **один процесс** (не кластер): лимиты запросов хранятся в памяти процесса.
- Каталог `data/` должен быть доступен на запись и сохраняться между перезапусками.
- Перед приложением нужен HTTPS (например, nginx), иначе в браузере не заработает микрофон.

Предупреждение `ExperimentalWarning: SQLite is an experimental feature` в логах — норма:
так Node.js помечает встроенный модуль `node:sqlite`.

## Где данные

- `data/ideas.db` — SQLite: таблица `ideas` (идеи, номер — порядковый) и `conversations`
  (переписки целиком, JSON). Открывается, например, программой DB Browser for SQLite.
- `data/ideas.csv` — копия каждой идеи строкой (открывается в Excel).
- `/admin` — список идей и полная карточка с диалогом.

`data/` в git не попадает. Для резервной копии достаточно копировать эту папку.

## Как устроен диалог

- На каждом шаге модель обязана вызвать функцию `respond`: своя реплика + найденные поля карточки.
  Свободного текста от модели нет, поэтому она не может «отправить» идею или придумать номер.
- Иногда Alice AI отдаёт вызов функции текстом (`[TOOL_CALL_START]…`) — это разбирается в
  `lib/text-tool-call.ts`. Реплика дополнительно чистится в `sanitizeReply` (`app/api/chat/route.ts`).
- Карточку хранит и проверяет код: `isCardComplete`, `authorStatus` в `lib/idea-template.ts`.
  Когда всё собрано, код показывает карточку с кнопкой «Всё верно — отправить».
- Отправка — только кнопкой (`app/api/submit`). Номер заявки и итоговый текст формирует код.
- Переписка восстанавливается после перезагрузки страницы (id диалога в `localStorage`).

## Где что менять

- `lib/idea-template.ts` — пункты карточки (порядок, обязательность, подсказки).
- `lib/company.ts` — описание компании для бота.
- `lib/prompt.ts` — инструкции модели.
- `lib/deliver.ts` — куда уходит отправленная идея (SQLite, CSV, письмо; позже — Google Таблица, Bitrix24).
- `lib/rate-limit.ts` — лимиты запросов.
- `app/api/transcribe/route.ts` + `components/voice-recorder.tsx` — голосовые через SpeechKit.

## Проверка диалога

Сервер должен быть запущен:
```bash
node scripts/dialog-tests.mjs       # все сценарии
node scripts/dialog-tests.mjs 3     # только сценарий № 3
```
Тесты создают идеи в базе — после прогона их стоит удалить (или запускать на копии `data/`).
